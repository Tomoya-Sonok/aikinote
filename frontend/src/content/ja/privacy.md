# AikiNote プライバシーポリシー

最終更新日: 2026年11月17日

AikiNote（以下「本サービス」）は、ユーザーの個人情報保護を重要視しています。本プライバシーポリシーは、本サービスにおける個人情報の取り扱いについて定めるものです。

## 1. 収集する情報

本サービスでは、以下の情報を収集します。

### 1.1 ユーザーが提供する情報

- **アカウント情報**: メールアドレス、ユーザー名、パスワード（ハッシュ化して保存）
- **プロフィール情報**: プロフィール画像、所属道場名、合気道開始時期
- **稽古記録**: タイトル、稽古内容、コメント、タグ、添付ファイル（画像・動画）

### 1.2 自動的に収集される情報

- **アクセスログ**: IPアドレス、ブラウザ種類、アクセス日時
- **Cookie情報**: セッション管理および認証、ならびに利用状況の計測（Microsoft Clarity）のために使用
- **利用状況データ**: ページ閲覧状況、機能の利用頻度、サービス内検索で使用されたキーワード等（個人を特定しない統計データとして、アクセス解析ツール「Umami」を通じて収集。なお、検索キーワードは機能改善のための傾向分析にのみ使用し、個人の特定には使用しません）
- **操作状況データ**: クリック・タップ、スクロール、画面遷移などの操作内容、および画面上の操作の様子を再現した記録（セッションリプレイ）。ユーザー体験向上のため、計測ツール「Microsoft Clarity」を通じて収集します（詳細は「7. Microsoft Clarity の利用について」をご覧ください）

## 2. 情報の利用目的

収集した情報は、以下の目的で利用します。

1. 本サービスの提供、維持、改善
2. ユーザーアカウントの管理および認証
3. ユーザーサポートの提供
4. 本サービスに関するお知らせの送付
5. 不正行為の防止およびセキュリティの確保
6. 統計データの作成および検索傾向・利用パターンの分析（個人を特定できない形で、サービスの改善を目的として）
7. 画面の使いやすさの検証および操作上のつまずきの把握（ユーザー体験の向上を目的として）

## 3. 情報の共有と開示

本サービスは、以下の場合を除き、ユーザーの個人情報を第三者に提供しません。

1. ユーザーの同意がある場合
2. 法令に基づく場合
3. 人の生命、身体または財産の保護のために必要がある場合
4. 本サービスの運営上必要な範囲で、業務委託先に提供する場合（適切な契約の下で管理）

## 4. 情報の保管とセキュリティ

1. ユーザーの個人情報は、セキュリティの高いクラウドサーバーに保管します。
2. データの送受信にはSSL/TLS暗号化通信を使用します。
3. パスワードは不可逆なハッシュ化を施して保存し、平文では保持しません。
4. 運営者は、個人情報への不正アクセス、漏洩、改ざん、紛失を防止するため、合理的な安全管理措置を講じます。

## 5. Cookieの使用

本サービスは、セッション管理および認証のためにCookieを使用します。また、利用状況の計測のために、Microsoft Clarity がファーストパーティCookieおよびサードパーティCookieを設定します。ブラウザの設定によりCookieを無効にすることも可能ですが、その場合本サービスの一部機能が利用できなくなる場合があります。

## 6. 外部サービスの利用

本サービスでは、サービスの提供・運営のために以下の外部サービスを利用しています。各サービスにおける情報の取り扱いについては、各社のプライバシーポリシーもあわせてご確認ください。

| サービス名 | 提供元 | 利用目的 |
|---|---|---|
| **Supabase** | Supabase, Inc. | ユーザー認証およびデータベース管理 |
| **AWS S3 / CloudFront** | Amazon Web Services, Inc. | 画像・動画データの保存および配信 |
| **Umami** | Umami Software, Inc. | アクセス解析（Cookieを使用しないプライバシー配慮型の利用状況分析） |
| **Microsoft Clarity** | Microsoft Corporation | ユーザー体験向上のための利用状況の計測（操作指標、ヒートマップ、セッションリプレイ。Cookieを使用） |
| **YouTube API** | Google LLC | ユーザーが入力したYouTube動画URLのプレビュー情報（OGP）の取得・表示 |
| **Google認証** | Google LLC | ソーシャルログイン機能 |
| **Resend** | Resend, Inc. | トランザクションメールの送信（認証メール、パスワードリセット等） |
| **Cloudflare** | Cloudflare, Inc. | CDN（コンテンツ配信）およびセキュリティ |

これらの外部サービスに対しては、本サービスの運営に必要な最小限の情報のみを提供し、適切な契約・設定のもとで管理しています。

## 7. Microsoft Clarity の利用について

本サービスでは、ユーザー体験向上のため、Microsoft Corporation が提供する計測ツール「Microsoft Clarity」を利用しています。

1. **収集する内容**: Microsoft Clarity は、操作指標、ヒートマップ、セッションリプレイを通じて、ユーザーが本サービスをどのように利用・操作したかを記録します。記録には、操作時に画面に表示されていた内容が含まれる場合があります。入力欄に入力された内容は、マスク（伏せ字化）された状態で記録されます。
2. **識別方法**: 利用状況のデータは、ファーストパーティCookieおよびサードパーティCookie等の技術を用いて、氏名やメールアドレスではなく仮名化された識別子に紐づけて収集されます。
3. **利用目的**: 運営者は、収集したデータを本サービスの画面や機能の改善のためにのみ利用します。
4. **Microsoft によるデータの取り扱い**: 収集されたデータは Microsoft Corporation に送信され、同社のプライバシーステートメントに基づき、サイトの最適化、不正防止・セキュリティ、広告等の目的で利用される場合があります。詳細は [Microsoft プライバシー ステートメント](https://www.microsoft.com/privacy/privacystatement) をご確認ください。
5. **無効化の方法**: ブラウザの設定でCookieを無効にすることで、Microsoft Clarity によるCookieの設定を止めることができます。

## 8. ユーザーの権利

ユーザーは、以下の権利を行使することができます。

1. **アクセス権**: 保有する個人情報の開示を請求する権利
2. **訂正権**: 個人情報の訂正、追加または削除を請求する権利
3. **削除権**: アカウントの削除を請求する権利
4. **データポータビリティ**: 個人データの書き出しを請求する権利

これらの権利を行使する場合は、本サービス内のヘルプ・問い合わせフォームよりご連絡ください。

## 9. 未成年者の利用

本サービスは、特定の年齢制限を設けていませんが、未成年者が利用する場合は保護者の同意を得ることを推奨します。

## 10. プライバシーポリシーの変更

本プライバシーポリシーは、必要に応じて変更することがあります。重要な変更がある場合は、本サービス内またはメールでお知らせします。変更後のプライバシーポリシーは、本ページに掲載した時点から効力を生じるものとします。

## 11. お問い合わせ

本プライバシーポリシーに関するお問い合わせは、本サービス内のヘルプ・問い合わせフォームよりお願いいたします。
